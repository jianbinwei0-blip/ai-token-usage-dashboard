# AI Usage Island

## Register

product

## Users

Developers use the dashboard's local Codex, Claude, Pi and DeepSeek Harness accounting while working in terminals and editors. The utility must support both external displays and notched MacBooks without placing content beneath the physical cutout.

## Product Purpose

Present the repository's trusted usage accounting in a compact, expandable native macOS island. This is a presentation layer, not a new collector or billing calculation, and it must run independently of SketchyBar.

## Brand Personality

Quiet, precise, familiar. Inherit the existing status strip's restrained appearance and complete caption/value fields. The user approved the compact/expanded island proposal in the implementation request.

## Anti-references

Do not squeeze the full strip into a permanently expanded banner. Do not add agent approvals, media playback, decorative charts, rotating metrics or animations on every refresh. Do not turn estimated cost into an apparent subscription charge.

## Design Principles

- Trust before novelty: preserve the canonical formatter, source scope, quota rules and stale/error markers.
- A glance answers today's tokens and remaining weekly quota. A click reveals the rest.
- The UI never owns a second accounting implementation. Refresh the existing collector with its five-minute cache and lock.
- Keep local installation reversible and login startup opt-in. Do not alter other presentation tools from the app installer.
- Native controls, keyboard access and truthful unavailable states take precedence over decorative effects.

## Accessibility & Inclusion

Provide labelled native buttons, semantic status text in addition to color, a menu-bar entry point, an optional system hotkey without Accessibility permissions, Escape to collapse, and reduced-motion-aware transitions. No known personal accessibility requirements were supplied; standard macOS accessibility is the baseline.

## Evidence

Derived from the accepted island proposal, the previous status strip, the dashboard's canonical formatter, the resource helper and observed NSScreen geometry. The repository owns accounting; the app bundles the formatter at build time for independent installed operation.
